# OnlyRep — 数据可视化日报工作台

> 把 Excel 变成一份好看的日报：**数据节点**负责把表算成数字，**日报画布**负责把数字摆成版面，**AI 助手**负责一句话替你搭好。一次搭好、换数即出图。
> 全程本地运行，数据不上传任何服务器；提供桌面应用（Windows）与单文件网页两种形态。

**曾用名**：RankBoard（排行榜制作器），v0.6.0 起统一更名 OnlyRep（历史 Release 资产保留）。

## 功能特性

### 1. 数据节点（管道计算）

类工作流的可视化管道：拖节点 → 连线成链 → 每步实时预览。

| 类别 | 节点 |
|---|---|
| 数据源 | 文件导入（xlsx/csv，多 sheet）、手填表（可直接编辑的表格）、表单（日期/参数，值进公式变量）、常量 |
| 筛选与整理 | 取行（前 N/区间/抽样）、筛选（条件过滤）、修数（批量规则改值 + 预览表双击定点改格）、排序·TopN |
| 计算与合并 | 计算字段（公式加列）、分组汇总、行差异（环比）、两表合并 |
| 取数与公式 | 取数（列聚合为变量）、公式节点（标量/逐行，进变量环境供画布引用） |

- 连线中点「⊕ 插入 | ✕ 删除」一步插节点；节点工具条支持添加下游、停用、删除、**✨ 问 AI**
- 每个节点右侧抽屉看实时输入/输出预览；同名列冲突 / 公式变量重名亮红提醒

### 2. 日报画布（自由版面）

- 组件：标题、富文本、KPI 指标卡、数据表格、图表（柱状/条形/折线/饼图/漏斗/雷达）、排行榜、logo、分栏容器（1~4 列可嵌套）
- 检查器 Figma 风格：灰底控件、内嵌前缀、分段对齐控件
- 绑定变量：KPI/图表/表格绑定管道算出的变量，换数据自动刷新
- 撤销/重做（Ctrl+Z，含操作名提示）、框选多选、结构树导航

### 3. AI 助手（右下角 ✨）

- **对话搭建**：「用这张表做渠道日报，三个 KPI + 柱状图」→ 动作卡一键采用（可撤销）
- **文件直传**：📎 把 xlsx/csv 发给助手，本机解析成数据源（不走 AI、不上传）
- **增量修改**：「把标题改成 XX」「把筛选条件改成只看短信」→ 只改点名部分（画布块 + 管道节点）
- **问答咨询**：「想做环比怎么配节点」→ 中文步骤化讲解，引用你的真实节点名
- 流式输出、Markdown 排版、校验失败自动自修、会话本机保存

### 4. 项目与模板

| | 模板 | 项目 |
|---|---|---|
| 内容 | 版式壳（组件+管道配置） | 壳 + **数据**（含原始文件字节） |
| 用途 | 分享、起始创建 | 日常工作单元 |

- 启动页：最近项目卡片（缩略图、固定/移除）、继续上次工作区、新建（空白/官方模板/我的模板/导入 .rkb）
- **.rkb 项目文件**：壳 + 原始表字节自包含，拷给同事导入即用；保存时自动双写到项目目录
- 保存提示：任意变更打脏标记（头部 💾 橙点），Ctrl+S 一键保存；深浅色模式全局切换

### 5. 导出

- 画布导出高清 PNG（缩放/留白可调，桌面端可选保存位置、导后一键打开文件夹）
- 网页单文件产物：双击即用、可内网分发

## 系统要求

- **操作系统**：Windows 10 / Windows 11（x64）
- **运行时**：WebView2（Windows 10/11 通常内置；缺失时安装包引导下载）
- **权限**：无需管理员权限（免安装单文件与按用户安装均可）
- **网页版**：现代浏览器（Chrome / Edge），无需安装任何东西

## 快速开始

1. **装数据**：新建项目 → 数据节点里加一个「文件导入」源节点，选你的日报源表
2. **搭版面**：日报画布视图，把 KPI 卡/图表/表格绑定到管道算出的变量（或直接 ✨ 让 AI 搭）
3. **天天复用**：明天换一张新表，「重读文件」全链路自动重算 → 导出 PNG 发群

## 数据与隐私

- **纯本地**：项目/模板存本机 SQLite（应用数据目录），缓存落浏览器 IndexedDB；**无任何遥测与后台联网**
- 导入文件原始字节随项目保存，换机器导入 .rkb 即完整还原
- **唯一主动网络出口**：你在「设置 → AI 助手」自行配置的 OpenAI 兼容端点（DeepSeek/通义/公司内网网关均可）。默认只发送**数据列结构（列名+类型）**；「发送数据样本」需你显式开启（附带每个数据源前 3 行）
- AI 生成内容请人工核对后再发往客户

## 🔧 开发（给开发同学）

```bash
npm install          # 装依赖
npm run dev          # 浏览器开发（5173）
npm run tauri:dev    # 桌面开发（热更）
npm run verify       # 提交前闸门：tsc + 290+ 单测 + 构建
npm run test:e2e     # 端到端回归（需先 build）
npm run tauri:build  # 出 exe + 安装包
```

**技术栈**：React 18 + TypeScript + Vite + Tailwind + Ant Design 6 + ECharts 6 + Zustand；Tauri 2（Rust：SQLite kv、导出落盘、单实例）；@e965/xlsx 解析 → 清洗管线 → 节点引擎（拓扑调度）；html-to-image 高清截图。

**工程规范**：本仓库遵循 [ONLYTOOLS Standard](https://github.com/onlytools-lab/onlytools-standard)（`AGENTS.md` + `onlytools.config.json`），变更与发布请按其流程执行。
