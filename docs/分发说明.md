# RankBoard 桌面版 · 分发说明（发版必读）

> 给分发者的说明：用户首次安装/打开可能遇到的提示与应对话术。

## ⚠️ Windows 蓝色安全警告（SmartScreen）

应用**未做代码签名**，用户首次运行 `rankboard.exe` 或安装包时，Windows 会弹蓝色窗口：

> **「Windows 已保护你的电脑」** — Microsoft Defender SmartScreen 阻止了无法识别的应用启动。

**这是正常现象，不是病毒**。引导用户：**点「更多信息」→ 点「仍要运行」**即可，之后不再出现。

- 银行内网环境如拦截更严格，请提前联系 IT 部门加白名单
- 彻底解法（后续）：购买 OV 代码签名证书（约 ¥2000+/年）或申请 EV 证书（直接过 SmartScreen）

## 📦 三种分发形态

| 形态 | 文件 | 说明 |
|---|---|---|
| **免安装 exe** | `src-tauri\target\release\rankboard.exe`（约 7MB） | 双击即用，推荐内部分发 |
| **NSIS 安装包** | `bundle\nsis\RankBoard_0.2.0_x64-setup.exe` | 标准安装体验（开始菜单/卸载） |
| **单文件网页** | `dist\index.html` | 双击在浏览器打开，适合临时使用 |

## 🗄️ 用户数据在哪（IT 备案用）

- 桌面端：工作区与模板库存于 `%APPDATA%\com.rankboard.app\rankboard.db`（SQLite 单文件，备份即复制）
- 网页版：浏览器 localStorage（清浏览器数据会丢，请提醒用户用「导出全部数据」备份）
- **所有数据均在用户本机，无任何网络上传**（应用无网络请求，可在防火墙层面验证）

## 🔄 版本升级

当前无自动更新。升级 = 分发新版 exe/安装包覆盖即可，**用户数据保留**（数据库独立存放，卸载不清除）。

用户如何确认版本：窗口标题栏右侧显示 `v0.2.0 · 构建时间`。

## 📋 发版检查清单

1. `npm run build` 构建前端
2. `npm run tauri:build` 出三份产物
3. 本机双击 exe 冒烟：开 app → 载入「银行转介漏斗（示例）」模板 → 导出图片 → 关闭重开数据还在
4. 版本号确认（package.json 的 version 是否与本次发版一致）
