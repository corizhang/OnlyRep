# RankBoard 日报画布 · 使用手册（5 分钟上手）

> 面向运营同事。全程本地运行，数据不上传任何服务器。

## 1. 打开方式（三选一）

| 方式 | 文件 | 适合 |
|---|---|---|
| 桌面应用（推荐） | `RankBoard_0.2.0_x64-setup.exe` 安装，或直接双击 `rankboard.exe` | 日常使用，数据存本地数据库，不占浏览器 |
| 单文件网页 | 双击 `dist\index.html` | 免安装尝鲜；数据存浏览器 |

首次打开会看到欢迎页：点「**载入示例，看看效果**」30 秒看完一个成品日报；或「从空白开始」。

## 2. 核心概念（就两个）

- **数据节点视图**（顶部切「数据节点」）：把 Excel 变成"算好的数字"。数据源（导入/手填表/表单/常量）→ 处理节点（筛选/取数/分组…）→ 连线成链。
- **日报画布**（顶部切「日报画布」）：把数字变成"好看的图"。左侧拖入组件（KPI 卡/数据表格/图表/排行榜…），右侧绑定刚才算好的变量，换数据自动刷新。

## 3. 最快路径：做出你的第一份日报

1. **导数据**：数据节点视图 → 左侧拖「文件导入」到画布 → 选择你的 xlsx/csv →（可多工作表切换）
2. **算数字**：点数据源节点 → 底部「添加下游」→ 加「取数」节点选列求和（或筛选/分组等）
3. **做版面**：切「日报画布」→ 左侧拖「KPI 指标卡」→ 右侧「数值」绑定刚才的取数变量
4. **出图**：右上「导出图片」→ 桌面端存到 `下载\RankBoard\`，网页端走浏览器下载

## 4. 常用操作速查

| 想做什么 | 怎么做 |
|---|---|
| 撤销/重做 | Ctrl+Z / Ctrl+Shift+Z（头部也有 ↩↪ 按钮，会提示撤了什么） |
| 批量移动节点 | 框选（Shift+拖空白）或 Ctrl+点选多个，拖任意一个整组动 |
| 删连线 | 点一下连线（变红）→ 按 Delete 或点中点 ✕ |
| 改节点名 | 直接点节点标题文字 |
| 调公式 | 点公式节点的 ƒx 弹窗（右侧有全部函数清单） |
| 看全部快捷键 | 右下角「?」按钮 |

## 5. 模板与备份（重要）

- **模板库**（头部「模板库」按钮）：搭好一份日报后「保存当前工作区」，以后一键切换/还原；日常编辑不回写，想更新存档再点一次保存
- **换电脑/换浏览器**：画布设置 →「数据迁移」→「导出全部数据」拷走 JSON，新环境「导入全部数据」即可（工作区+模板库一起带走）
- **桌面端数据位置**：`%APPDATA%\com.rankboard.app\rankboard.db`（备份=复制这一个文件）

## 6. 遇到问题

- 顶部红色警告条出现 → 本地存储写不进去了，**立刻点「立即导出模板备份」**
- 页面白屏 → 崩溃页有「导出模板救数据」按钮，先导出再刷新
- 数据不对 → 看画布上的节点有没有红色错误角标，悬停看原因
