# OnlyRep 变更说明：AI 助手（内置 AI 能力）

> 面向团队同步 · 2026-11-25 · 适用版本 v0.6.0+

## 🎯 一句话

编辑器内置了 AI 助手：**右下角对话框形式**，能聊天、能传 Excel、能直接帮你把日报画布和数据管道搭出来，还能回答"想做 XX 效果该怎么配节点"。

## ✨ 有什么新东西

### 1. AI 助手入口与会话面板

- 画布右下角的 **✨ 悬浮按钮**，点开即聊（主流 AI 助手形态），不用时收起不占地方
- 顶栏的「✨ AI 生成」按钮同样打开助手
- 面板宽度可拖（左缘拖动），会话记录本机保存，重开还在

### 2. 输入框直接传文件

- 输入框旁 **📎 回形针**，直接把 xlsx / csv 发给助手
- 文件在**本机解析**（不走 AI、不上传），自动变成画布里的数据源，助手立即知道你的表有哪些列

### 3. 多轮对话 + 两类回答

| 你怎么说 | AI 怎么做 |
|---|---|
| 「基于我传的表做一份渠道转介日报，带三个 KPI 和柱状图」 | 生成完整画布配置，以**动作卡**形式给出，点「采用」即落地（Ctrl+Z 可撤销） |
| 「把标题改成 11 月渠道日报」「把第二个 KPI 改成公众号新增」 | 输出**增量修改卡**（只改你点名的部分，不推倒重来），同样一键采用可撤销 |
| 「想做环比对比，节点怎么配？」 | 用中文一步步讲清楚配法（不生成配置） |

### 4. 回答"说人话"

- AI 回答按 Markdown 排版（步骤清单、代码块、加粗都有排版）
- 提到的节点类型自动显示为中文：**修数节点（cellEdit）**、**筛选节点（filter）**
- 提到你画布里的节点时直接显示**你改过的节点名**（如「转介统计」），不再甩一串英文 id

## 🔧 使用前的一次性配置

「设置 → AI 助手」填三项（OpenAI 兼容格式，DeepSeek / 通义千问 / 公司内网网关均可）：

| 项 | 说明 |
|---|---|
| 服务端点 | 服务地址，形如 `https://你的服务/v1` |
| API Key | 只存在你自己电脑上 |
| 模型 | 如 deepseek-chat / qwen-plus |

## 🔒 数据安全（重要）

- **默认只把"列名+类型"发给 AI**，数据行不出本机；想要 AI 更贴合可在设置里打开「发送数据样本」（会附带每个数据源前 3 行）
- 密钥仅本机保存；除你配置的 AI 端点外不连任何服务器
- ⚠️ AI 生成的内容（文案、数字口径）**务必人工核对后再发客户**

## ⚠️ 已知边界

- 增量修改目前覆盖：改标题/主题/画布参数、加/改/删画布块；**管道节点的局部修改暂不支持**（可整链重新生成）
- 多轮对话有长度窗口（最近 12 条），超长会话建议开新对话
- AI 偶发"答非所问"时，把需求拆细、指明数据列名会明显更准

## 🧪 推荐体验路径（3 分钟）

1. 设置里配好 AI 三项
2. 右下角 ✨ → 📎 传一张你的日报源表
3. 说：「用这张表做一份渠道日报：顶部三个 KPI（总新增、公众号新增、短信新增），中间柱状图按渠道对比，底部明细表」
4. 生成后说：「把标题改成 XX」体验增量修改
